> 文档性质：毕业论文总体研究设计与边界决策文档  
> 适用阶段：开题完善、方法设计、实验组织、章节写作与最终审校  
> 形成日期：2026-08-02  
> 说明：本文档整合现有材料，但不替代、不修改原文档，也不以某一版代码实现限定论文的完整研究空间。

## 1. 方案依据与使用原则

本方案依据以下文档综合形成：

- `AGENTS.md`
- `KAFNet-ProFITi工业异步传感器状态预测缝合方案.md`
- `统一对比实验方案.md`
- `补充建议.md`
- `3.2_结构框架.md`
- `开题报告_2_3_6对应修改建议.md`

这些材料分别承担不同作用：

| 材料 | 在本方案中的作用 | 不直接继承的内容 |
|---|---|---|
| `AGENTS.md` | 仓库治理、实验复现、引用与结果追溯的最高约束 | 不把示例命令视为论文方法定义 |
| 初始缝合方案 | 提供表示层、概率层、风险层的技术来源与接口思路 | 不把“两个模型顺序拼接”作为论文贡献 |
| 统一对比实验方案 | 提供公平比较、数据划分、指标和结果保存规范 | 不把尚未完整运行的模型或数值视为已完成证据 |
| 补充建议 | 提供命名、校准、统计可信度和答辩风险提醒 | 不让某一当前实现锁死最终方法形态 |
| 3.2 结构框架 | 提供六章结构及第三至第五章的递进关系 | 不允许章节之间重复证明同一结论 |
| 开题报告对应修改建议 | 提供研究意义、研究内容、创新点和重点难点的统一表述 | 不将建议稿直接视为已有实验结论 |

当材料之间出现冲突时，采用以下决策顺序：

1. 学术问题和证据闭环优先于模型名称及当前工程形态。
2. 数据无泄露、公平对比和结果可追溯优先于扩大实验规模。
3. 章节职责和创新点一一对应优先于堆叠模块或增加指标。
4. 可被实验独立验证的机制优先于无法拆分的系统性描述。
5. 代码实现是研究方案的验证载体，不是整篇论文研究边界的唯一来源。

### 1.1 与来源文档的一致性审查

经逐项对照，本方案与六份依据材料在研究对象、三层贡献、章节递进、数据集角色和风险校准原则上没有实质冲突。差异主要来自论文层级的抽象、证据门槛的收紧，以及对当前实现和完整研究目标的区分。

| 审查项 | 来源文档口径 | 本方案处理 | 审查结论 |
|---|---|---|---|
| 总体任务 | 工业异步多传感器未来状态概率预测，风险为辅助任务 | 保持主任务与辅助任务分层 | 一致 |
| 三层研究内容 | 规整表示、联合概率预测、风险评估与校准 | 固化为三项创新和第三至第五章证据链 | 一致 |
| 模型定位 | 初始路线为 KAFNet-ProFITi，当前工程主模型为 KST ProbFlow | 论文层使用机制名称，正式实验层仍需冻结唯一主模型版本 | 层级扩展，不构成冲突 |
| 第三章边界 | 使用轻量预测头独立验证表示，不使用完整概率头和风险头 | 保持独立验证要求 | 一致 |
| 第四章边界 | 集中验证多传感器概率预测及相关结构 | 增加联合建模证据门槛和多变量评分 | 合理收紧 |
| 第五章边界 | 风险分数、验证集阈值、Platt 校准和风险鲁棒性 | 区分分布派生风险与辅助监督风险 | 合理澄清 |
| 数据集角色 | MetroPT-3 为主，C-MAPSS 与 TEP 为辅助 | 保持相同角色并限定各自结论权限 | 一致 |
| MetroPT-3 协议 | chronological 50/20/30 为非官方风险补充协议 | 保留该说明，并要求披露事件和正类数量 | 一致并收紧披露要求 |
| 缺失类型 | 初始事件格式包含缺失类型，正式张量协议主要使用 mask 和时间信息 | 仅在缺失来源可追溯时使用缺失类型，否则只使用可观测字段 | 修正潜在过度要求 |
| 统计可信度 | 三个 seed、均值与标准差、bootstrap 置信区间 | 进一步要求按事件、设备或时间块处理相关样本 | 合理收紧 |

审查中需要保留两个层级。论文总体方案可以不受当前某一代码版本限制，但正式实验启动前必须确定唯一主模型定义、损失、输入输出和模型名。论文可以规划完整联合概率研究，但只有达到联合建模证据门槛后，才能在最终结论中使用相应强表述。

## 2. 论文总体定位

### 2.1 建议题目

建议使用不依赖具体模型版本、能够覆盖三层研究内容的题目：

**面向工业设备异步多传感器的概率状态预测与风险评估方法研究**

如需要突出表示学习，可采用：

**面向工业异步多传感器的规整表示、联合概率预测与风险评估方法研究**

模型名称适合在方法章节中使用，不建议将“KAFNet-ProFITi 缝合”作为正式论文题目或总贡献表述。

### 2.2 核心研究对象

论文的核心研究对象是：

> 在异步采样、局部缺失、通道降采样、连续离线和复杂工况条件下，根据工业设备多传感器历史观测，对未来多传感器连续状态进行概率预测，并将预测分布转化为经过验证集校准的风险信息。

主任务、辅助任务和非主任务必须严格区分：

| 层级 | 任务 | 定位 |
|---|---|---|
| 主任务 | 未来多传感器连续状态的概率预测 | 全文评价中心，必须同时报告点预测、分布质量和区间质量 |
| 辅助任务 | 基于未来状态分布的风险评分、校准与预警分析 | 证明概率输出具有工业决策价值，但不能取代主任务 |
| 数据集特定辅助任务 | C-MAPSS 的 RUL 阈值风险、TEP 的故障时段风险 | 用于跨场景验证，不改变统一主任务 |
| 非主任务 | 纯故障分类、纯 RUL 回归、故障诊断系统开发 | 不作为本文主要贡献，除非后续另设专门模型和实验 |

### 2.3 总体研究命题

全文围绕一个总命题展开：

> 将工业传感器的观测过程、未来状态分布和风险决策过程统一建模，能够比“插补—点预测—独立分类”的分离式流程更完整地表达异步多传感器系统的状态信息、不确定性和运维风险。

该总命题拆分为三个连续且不能互相替代的子问题：

1. 如何在不把填充值误认为真实观测的前提下，将不规则、多源、部分缺失的历史事件转化为可比较的状态表示？
2. 如何由历史状态表示生成未来多个时间点、多个传感器的概率分布，并表达边际不确定性及跨变量相关性？
3. 如何将预测分布转化为不依赖测试集调参、能够解释报警依据的风险分数和预警结果？

## 3. 总体研究边界

### 3.1 纳入范围

- 工业多元时间序列中的异步采样、人工缺失、通道降采样和连续离线。
- 时间戳、观测掩码、通道身份、时间间隔和工况变量的统一表示。
- 长历史趋势、局部动态和跨传感器关系的状态表示学习。
- 未来多传感器连续值的点预测、边际概率预测和相关性感知概率预测。
- 预测均值、预测样本、分位数区间及其校准。
- 基于预测分布或分布特征构造的风险评分、验证集阈值和概率校准。
- MetroPT-3 主验证，以及 C-MAPSS、TEP 的辅助验证。
- 缺失鲁棒性、消融、超参数敏感性、统计可信度和计算效率分析。

### 3.2 排除范围

- 不把所有数据集描述为原生异步数据。对规则采样数据人工构造异步性时必须明确说明。
- 不把未来传感器预测等同于直接 RUL 预测或故障分类。
- 不在测试集上选择报警阈值、拟合校准器、选择超参数或挑选 checkpoint。
- 不直接引用不同论文、不同划分或不同缺失条件下的 SOTA 数值作为公平对比。
- 不将不同数据集上的 AUROC、AUPRC、F1 视为同一风险尺度上的横向排名。
- 不因模型模块较多而自动宣称多个创新点；每项创新必须有独立问题、方法和证据。
- 不将一次单 seed 结果、smoke test 或缺少运行溯源的表格数值写成最终结论。
- 不手工修改 `result/` 下的指标文件或脱离 `run_id`、seed、checkpoint 引用实验数值。

## 4. 三项核心创新的完整定义

三项创新分别对应第三、第四、第五章。每项创新都必须满足“问题独立、方法独立、实验可拆、结论有限”四个条件。

### 4.1 创新一：观测过程感知的异步多传感器规整表示

**研究问题**

传统插值或规则重采样容易模糊真实观测、未观测和连续离线之间的差异，也可能抹去不同传感器采样频率和工况变化所携带的信息。

**方法主张**

将观测值、时间戳、观测掩码、通道身份、时间间隔和可获得的工况状态共同纳入观测建模；只有在缺失来源可由采集日志或受控模拟可靠区分时，才增加缺失类型。通过多尺度时间聚合、变量级状态压缩和跨传感器交互，将异步事件转换为固定维度但保留观测过程信息的规整表示。

**学术增量**

创新不在于“增加 mask 通道”，而在于把观测过程本身作为设备状态建模的一部分，并证明这种表示在不同缺失机制、不同信息密度和不同工况下具有独立价值。

**必须完成的工作**

- 建立统一事件表示和张量协议，明确每个字段的含义、形状和缺失语义。
- 设计随机缺失、通道级降采样和连续离线三类可复现机制。
- 构建同时保留长周期趋势与局部动态的表示编码方法。
- 明确工况变量的来源、可用性和注入方式。
- 使用轻量、统一的预测头独立检验表示质量，避免最终概率头替表示模块“代答”。

**关键证据**

- 与线性插值、前向填充、仅 mask 建模、缺失衰减和连续时间方法的比较。
- 时间戳、mask、通道身份、工况信息、多尺度分支和跨传感器交互的逐项消融。
- 0%、10%、30%、50%、70% 缺失率及不同缺失机制下的性能曲线。
- MAE、RMSE、相对性能下降、参数量、训练时间和推理时间。

**允许声称**

在给定数据协议和缺失机制下，所提表示改善了异步缺失条件下的状态表征或预测稳健性。

**禁止越界**

不能仅凭最终完整模型优于基线，就把改进归因于规整表示；不能把人工异步实验表述为真实现场原生异步验证。

### 4.2 创新二：查询条件驱动的多传感器概率状态预测

**研究问题**

点预测只给出条件均值，独立概率头只能给出单变量不确定性，均难以充分表达多传感器协同变化、联合异常和预测窗口内的相关结构。

**方法主张**

以创新一得到的变量级历史表示为条件，结合未来时间、目标通道和工况信息形成查询项级条件表示；在此基础上学习未来多传感器的边际分布、预测区间和相关结构，输出预测均值、样本与分位数。

**学术增量**

创新不在于“把编码器接到概率头”，而在于建立历史变量状态与未来查询项之间的条件映射，并证明相关结构建模相对于点预测、独立高斯和独立概率预测具有必要性。

**必须完成的工作**

- 定义未来查询集合及固定排序，保证目标展开与条件表示严格一致。
- 设计从变量级表示到查询项级条件表示的映射。
- 建立稳定的边际概率建模、区间输出和相关结构建模机制。
- 明确训练目标中点预测、概率密度、分位数和相关结构各自承担的作用。
- 处理高维预测窗口下的数值稳定性、计算复杂度和采样稳定性。

**关键证据**

- 与点预测、对角高斯、边际概率模型、代表性不规则概率模型的统一比较。
- 去除查询条件、改变查询排序、移除相关结构、替换概率头和移除区间目标的消融。
- MAE、RMSE、平均每个有效目标的 NLL、CRPS、PICP、MPIW 和 Energy Score。
- 预测区间、联合样本、传感器相关结构和极端窗口的可视化。
- 不同预测长度、隐维度、相关结构容量和采样数下的敏感性与效率分析。

**联合建模的证据门槛**

只有同时满足以下条件，论文才可使用“联合概率分布建模”作为强结论：

1. 相关结构参数参与可验证的训练目标，而不只是推理时生成相关噪声。
2. 模型的概率定义、似然或采样机制在数学上自洽。
3. 除边际 NLL、CRPS 外，至少使用 Energy Score 或其他多变量评分验证依赖结构。
4. 与独立边际模型的差异通过受控消融获得，而非通过不同编码器或不同训练配置获得。

若上述条件未全部满足，应使用“相关性感知概率预测”或“低秩相关概率采样”这一较弱表述，不夸大为严格联合密度学习。

**允许声称**

在公平协议下，所提条件概率预测方法改善了点预测、分布质量、区间覆盖或多变量评分中的一项或多项，并说明这些指标之间的权衡。

**禁止越界**

不能仅凭 PICP 提高声称概率预测更好；区间过宽同样可以提高覆盖率。不能用不可比的 NLL 定义直接排名，也不能只用边际 CRPS 证明跨变量联合结构有效。

### 4.3 创新三：由预测分布到工业风险的校准评估机制

**研究问题**

概率预测质量并不自动等于风险可用性。工业报警需要明确风险来源、阈值来源、误报预算、概率校准和故障事件解释。

**方法主张**

从未来状态分布中提取阈值越界概率、区间宽度、预测方差和窗口级风险特征，形成传感器级与设备级风险分数；仅使用验证集拟合校准器并确定报警阈值，再固定应用于测试集。

**学术增量**

创新不在于附加一个二分类头，而在于建立“状态分布—风险分数—概率校准—报警决策”的可追溯转换链，并研究预测质量、校准质量和风险识别能力不一致时的适用边界。

**必须完成的工作**

- 分开定义分布派生风险和辅助监督风险，禁止在结果中混用两类分数。
- 为每个数据集独立定义风险标签、事件单位、预警窗口和可解释范围。
- 固定 validation-only 校准和阈值选择流程。
- 构建风险时间线、误报、漏报、事件级检出和提前量分析。
- 分析缺失率、缺失机制和校准设置对风险稳定性的影响。

**正式风险口径**

- 校准器只在 validation split 上拟合。
- 正式阈值采用校准后 validation 正常风险分数的 `q=0.95` 分位数。
- AUROC、AUPRC 使用固定 test 分数评价排序能力。
- F1、Precision、Recall 使用固定 validation-derived 阈值。
- ECE 使用校准后概率并明确分箱方案。
- `validation_best_f1` 和 `test_best_f1` 仅为诊断项，不进入正式主表。

**关键证据**

- 原始分数、仅分位阈值、Platt 校准加分位阈值的对比。
- AUROC、AUPRC、F1、Precision、Recall、ECE、误报率和漏报率。
- 具有明确故障时刻时的事件级检出率和 Lead Time。
- 可靠性曲线、风险时间线和典型误报/漏报案例。
- 风险指标在不同缺失机制下的稳定性。

**允许声称**

在特定数据协议和风险定义下，预测分布能够支持经过验证集校准的风险排序或报警决策。

**禁止越界**

不能将窗口级高 AUROC 直接表述为真实维护收益；不能在没有明确故障时间时报告稳定的提前预警能力；不能把 C-MAPSS 的辅助 RUL 阈值风险称为直接 RUL 预测。

## 5. 论文工作体系

整篇论文应完成七类相互连接的工作。它们不是七个创新点，而是支撑三项创新成立的完整工作体系。

| 工作包 | 核心内容 | 主要产物 | 支撑创新 |
|---|---|---|---|
| W0 问题形式化 | 定义事件、历史窗口、未来查询、目标、mask、工况和风险 | 符号表、任务定义、假设与边界 | 全部 |
| W1 数据与协议 | 数据读取、划分、归一化、窗口、异步缺失、风险标签 | 固定 split、mask、数据统计与事件分布 | 创新一、三 |
| W2 规整表示 | 观测过程编码、多尺度历史、变量交互、工况建模 | 表示编码器与轻量预测验证 | 创新一 |
| W3 概率预测 | 查询条件、边际分布、相关结构、区间与采样 | 概率模型、训练目标与推理输出 | 创新二 |
| W4 风险评估 | 风险构造、校准、阈值、风险时间线 | 校准文件、风险表与案例图 | 创新三 |
| W5 统一实验 | 基线、消融、鲁棒性、敏感性、统计、效率 | Table 1-7、Fig. 1-8、统计报告 | 全部 |
| W6 论文证据治理 | run 溯源、引用、术语、图表与章节交叉引用 | 证据清单、章节稿与复核记录 | 全部 |

工作包之间必须满足以下依赖：

```text
W0 问题形式化
  -> W1 数据与协议
  -> W2 规整表示
  -> W3 概率预测
  -> W4 风险评估
  -> W5 统一实验
  -> W6 论文证据治理
```

W2、W3、W4 分别对应三项创新。W1、W5、W6 是三项创新能够被相信的共同基础，不能被当作一般工程杂务省略。

## 6. 方法总体架构

总体方法应保持实现无关的五层结构：

```text
工业多源观测
  -> 异步事件与缺失协议层
  -> 观测过程感知的规整表示层
  -> 查询条件驱动的概率状态预测层
  -> 分布到风险的转换与校准层
  -> 预测、区间、风险和解释输出
```

### 6.1 各层职责

| 层 | 输入 | 输出 | 必须回答的问题 |
|---|---|---|---|
| 协议层 | 原始传感器表、时间、工况、故障记录 | 事件、张量、split、mask、标签 | 数据是否无泄露且可复现 |
| 表示层 | 历史事件、mask、工况 | 变量级历史状态 | 是否保留观测过程并改善表示质量 |
| 概率层 | 历史状态、未来时间和通道查询 | 预测分布、样本、分位数 | 是否表达未来不确定性及相关结构 |
| 风险层 | 预测分布及数据集风险规则 | 风险概率、阈值和报警 | 是否校准、是否可解释、是否依赖测试标签 |
| 输出层 | 所有模型输出与评估结果 | 表格、图、案例和结论 | 每项结论能否追溯到实验事实 |

### 6.2 技术名称的使用边界

- `KAFNet-ProFITi`：作为初始技术路线、来源模型组合或受控对照，不代表整篇论文只能采用原始完整模块。
- `KST ProbFlow`：可作为最终模型名称或一个主要实现，但其具体模块应服务于三项创新，不反向定义创新。
- 正文总论述优先使用“异步规整表示”“查询条件概率预测”“相关结构建模”“验证集风险校准”等机制名称。
- 只有方法定义和实验对象完全一致时，才在表格中使用具体模型名。

论文层与实验层的命名不能混用。论文层允许围绕完整研究问题调整技术实现；正式实验层必须冻结一个唯一主模型版本，并统一模型名称、模块组成、损失函数、配置、checkpoint 选择和结果文件。若后续实现与当前方案不同，应将它记录为方法演进或受控变体，而不能用同一个模型名覆盖不同结构。

## 7. 数据集角色与结论权限

### 7.1 MetroPT-3

**角色：主数据集。** 用于完整验证状态预测、概率预测、风险校准和缺失鲁棒性。

- 数据本身以规则采样为主，论文必须明确异步性来自可复现模拟。
- `metropt3_chrono_502030` 可作为风险主评估补充协议，但不是 UCI 官方协议。
- 选择 50/20/30 的理由是测试段保留风险正类，必须同时报告故障事件分布和正类窗口数量。
- 官方或接近官方的 first-month 协议适合作为分布漂移压力测试。
- 若某划分测试集无正类，只报告预测指标和风险分数趋势，风险分类指标记为不可用。

### 7.2 C-MAPSS

**角色：退化、多工况辅助验证。** 优先验证工况条件、跨设备泛化和传感器概率预测。

- 必须按 engine id 划分，官方 test 保持独立。
- FD004 最适合验证多工况、多故障模式；FD001 可作为较简单辅助场景。
- RUL 阈值只用于辅助风险标签。没有专门 RUL 输出头时，不声称完成概率 RUL 预测。
- 不将 C-MAPSS 风险指标与 MetroPT-3 风险指标作绝对数值比较。

### 7.3 Tennessee Eastman Process

**角色：过程工业故障场景辅助验证。** 用于检验跨行业适用性和故障注入后的风险响应。

- 必须按 `simulationRun` 划分，不能按时间点随机拆分。
- 故障注入点以所用数据版本说明为准，并进入配置与数据统计表。
- 规则采样数据上的异步性需要人工构造并明确披露。
- TEP 是增强外部有效性的辅助证据，不应挤占 MetroPT-3 主实验闭环。

## 8. 统一实验与证据矩阵

### 8.1 E0：数据协议有效性

**目的：** 证明结论不依赖数据泄露、随机窗口拆分或不同模型使用不同缺失样本。

**比较：** 统一事件协议、规则重采样、直接插值；不同缺失机制的实际保留率。

**产物：** 数据划分表、时间线图、故障事件分布、mask 统计和归一化来源说明。

### 8.2 E1：规整表示独立实验

**目的：** 只回答创新一，不使用完整概率头或风险头代替表示验证。

**模型：** 插值加轻量预测器、前向填充加轻量预测器、Masked 模型、GRU-D、ODE-RNN 或 mTAN、本文表示加同规格轻量预测头。

**指标：** MAE、RMSE、相对退化率、参数量、训练时间和推理时间。

### 8.3 E2：概率状态预测主实验

**目的：** 回答创新二，比较点预测、独立概率预测和相关性感知概率预测。

**模型族：** TCN-Gaussian、PatchTST-Gaussian 或 iTransformer-Gaussian、GRU-D、ODE-RNN、mTAN、GraFITi、ProFITi、KAFNet、独立高斯消融、边际概率消融和完整方法。

**指标：** MAE、RMSE、NLL、CRPS、PICP、MPIW、Energy Score、参数量和推理时间。

### 8.4 E3：风险与校准实验

**目的：** 回答创新三，验证风险排序、固定阈值决策和概率可信度。

**设置：** 原始分数、validation normal q95、Platt 加 validation normal q95；阈值固定后一次性测试。

**指标：** AUROC、AUPRC、F1、Precision、Recall、ECE、误报率、漏报率，以及条件满足时的事件级 Lead Time。

### 8.5 E4：缺失鲁棒性

第三章与第五章可以使用相同缺失设置，但回答不同问题：

| 章节 | 关注对象 | 主要指标 |
|---|---|---|
| 第三章 | 表示和连续状态预测是否稳定 | MAE、RMSE、相对退化率 |
| 第五章 | 风险排序、校准和报警是否稳定 | AUROC、AUPRC、F1、ECE、风险漂移 |

故障相关缺失只能作为额外压力测试。由于其构造可能使用故障信息，不能作为主实验，也不能让模型通过缺失模式直接读取标签。

### 8.6 E5：消融与敏感性

每个核心模块必须只有一个主要理论职责，并有对应消融：

| 机制 | 首要问题 | 首要指标 |
|---|---|---|
| 多尺度历史表示 | 是否兼顾长趋势与局部异常 | MAE、RMSE |
| 时间、mask、通道和工况编码 | 观测过程信息是否必要 | MAE、鲁棒性下降 |
| 跨传感器交互 | 变量关系是否有贡献 | Energy Score、CRPS |
| 查询条件映射 | 未来时间与通道条件是否必要 | NLL、CRPS |
| 相关结构概率头 | 独立边际是否不足 | Energy Score、NLL |
| 分位数或区间目标 | 区间质量是否改善 | PICP、MPIW |
| 风险构造与辅助监督 | 风险是否来自有效预测信息 | AUPRC、F1 |
| Platt 校准 | 概率刻度是否更可信 | ECE、可靠性曲线 |

敏感性分析按章节分开：第三章分析表示超参数，第四章分析概率与预测超参数，第五章分析阈值、校准和风险窗口，不跨章重复。

### 8.7 E6：统计与效率

- 核心模型使用 seeds `2026`、`2027`、`2028`，报告 `mean ± std`。
- 单 seed 基线只能作为阶段性结果，不能与三 seed 主模型作同等强度结论。
- MetroPT-3 风险正类少且相邻窗口高度相关，置信区间应采用事件级、设备级或时间块 bootstrap，不能把所有窗口视为独立样本。
- Wilcoxon 检验必须建立在足够数量、含义一致的配对单位上；不能仅用 3 个 seed 得出稳定显著性结论。
- 效率比较固定硬件、batch size、精度模式、预测长度和采样数，并分别报告训练与推理开销。

## 9. 公平性与防泄露硬规则

1. 先划分 train、validation、test，再生成滑动窗口；任何窗口不得跨越 split 边界。
2. C-MAPSS 按 engine、TEP 按 simulation run、MetroPT-3 按时间划分。
3. 归一化统计量只来自 train split，并由所有模型复用。
4. 同一数据集、seed、缺失率和缺失机制复用同一固定 mask 文件。
5. 所有模型使用相同历史长度、预测长度、stride、目标通道和风险标签规则。
6. 模型选择和 checkpoint 选择只使用 validation 指标；建议统一使用 validation CRPS。
7. 超参数搜索只在 train/validation 上进行，test 只执行冻结配置的最终评估。
8. 风险校准器与阈值只在 validation 上确定，禁止任何形式的 test-label 搜索。
9. 点预测基线若参与概率指标比较，应使用统一定义、统一训练规则的概率输出头。
10. NLL 必须统一为每个有效目标的平均负对数密度，说明标准化空间、分布族和 mask 归一化。
11. 跨模型主区间比较优先使用所有概率模型均可生成的样本区间；专用 QuantileHead 或 conformal 区间另表报告，不能混为同一列。
12. 完整实验与 smoke test 严格分开，任何截断 batch、少量 epoch 或调试结果不得进入论文主表。

## 10. 六章结构与职责边界

### 第一章：提出问题，不预支结论

- 从工业预测性维护转向异步观测、概率状态和风险决策。
- 综述状态预测、不规则时间序列、概率预测和风险校准。
- 提出三个研究问题、三项研究内容和三项创新。
- 创新表述使用“提出并验证”的目标语言，不写尚未获得的性能结论。

### 第二章：提供理论工具，不重复文献综述

- 定义工业多元状态预测、异步观测和缺失机制。
- 介绍规整表示、多尺度建模、条件概率预测及相关结构。
- 定义 NLL、CRPS、Energy Score、PICP、MPIW、AUROC、AUPRC、F1 和 ECE。
- 说明验证集校准、报警预算和数据泄露边界。

### 第三章：只证明规整表示

- 形式化事件序列和统一张量协议。
- 说明数据集适配、缺失机制和工况信息。
- 设计观测过程感知的规整表示方法。
- 使用相同轻量预测头完成独立表示对比、消融和鲁棒性实验。
- 风险标签可在数据协议中定义，但风险结果和校准结论留到第五章。

### 第四章：只证明概率状态预测

- 在第三章表示之上构建未来查询条件。
- 建立边际不确定性、区间和相关结构建模方法。
- 统一报告点误差、分布质量、多变量评分和区间质量。
- 完成概率头、查询方式和相关结构消融及敏感性分析。
- 不在本章调整报警阈值，不用风险 F1 代替概率预测证据。

### 第五章：只证明风险转换与校准

- 明确每个数据集的风险定义和结论权限。
- 区分分布派生风险、辅助风险头和校准后风险概率。
- 固定 validation-only Platt calibration 与 q95 阈值。
- 报告风险排序、阈值决策、校准、时间线和缺失鲁棒性。
- 讨论预测误差、概率质量和风险可用性不一致的情况。

### 第六章：只总结已有证据

- 三项总结逐一对应第三、第四、第五章的已验证结论。
- 局限性至少覆盖人工异步、少故障事件、跨数据集风险定义差异和高维相关建模代价。
- 展望可以包括原生异步数据、在线校准、因果缺失机制和实际维护决策，但不得写成已完成贡献。

## 11. 整篇论文的结构化论证框架

本节规定整篇论文如何回答“别人怎么做、现有方法解决了什么、为什么仍不足、本文为什么这样设计、这种设计为什么可能更好、如何证明”的问题。它不是简单目录，而是全文统一的论证骨架。

### 11.1 全文统一论证链

每个核心章节和关键小节均按七个环节展开：

| 环节 | 要回答的问题 | 主要依据 | 写作边界 |
|---|---|---|---|
| 研究场景 | 工业设备中出现了什么具体问题 | 数据事实、行业文献、数据集统计 | 不用空泛的“工业智能化需求”代替具体矛盾 |
| 已有路线 | 代表性研究通常如何处理该问题 | 可核验文献、原始模型和综述 | 按方法范式组织，不按作者名单罗列 |
| 已有价值 | 这些方法已经解决了什么 | 原文结论及适用条件 | 不通过贬低基线制造创新性 |
| 目标缺口 | 在本文数据条件和任务目标下还缺什么 | 文献边界、协议差异、预实验或理论分析 | 缺口必须针对本文场景，不能写成普遍失效 |
| 本文选择 | 本文采用什么机制回应缺口 | 方法定义、公式和总体架构 | 每个机制只能对应一个首要问题 |
| 机制理由 | 为什么该机制有望改善目标问题 | 信息流、概率定义、复杂度和因果链分析 | 这里写预期优势，不预写实验胜利 |
| 证据闭环 | 用什么对照和指标判断是否成立 | 主实验、消融、鲁棒性、统计和案例 | 结果不支持时必须降低结论强度 |

全文的简化逻辑为：

```text
工业场景中的具体矛盾
  -> 已有方法范式及其有效部分
  -> 在异步概率状态预测任务中的剩余缺口
  -> 本文对应的机制选择
  -> 该选择的作用路径与可检验假设
  -> 公平实验和数据证据
  -> 结论范围、代价与局限
```

### 11.2 “为什么这样做”和“为什么好”的证据层级

“为什么这样做”与“这样做为什么好”不能混成一句价值判断，应拆成三个证据层级：

| 层级 | 论证内容 | 合法写法 | 不充分写法 |
|---|---|---|---|
| 机制合理性 | 设计是否对准已识别的问题 | mask 参与聚合可避免把填充值当作真实观测 | 模块更复杂，所以表达能力更强 |
| 实证有效性 | 机制是否在公平实验中产生预期变化 | 同一轻量头下，表示消融使 MAE 和鲁棒性下降 | 完整模型最好，所以所有模块都有效 |
| 工业可用性 | 改进是否转化为校准、稳定或效率收益 | 固定验证集阈值下误报和漏报达到明确水平 | AUROC 高，所以可直接部署 |

方法章节在实验完成前使用“用于”“旨在”“预期能够”等机制性表述。实验结果形成后，才根据数据使用“改善”“降低”“保持”等结果性表述。结论章节只保留已经通过主实验和消融共同支持的判断。

### 11.3 第一章的论证结构：从工业问题到研究问题

第一章承担“为什么值得研究”和“为什么必须形成三层方案”的论证，不展开具体网络结构。

| 写作单元 | 别人怎么做 | 仍存在的问题 | 本文为什么这样做 | 本章产出 |
|---|---|---|---|---|
| 工业状态预测 | 点预测、RUL、故障诊断和健康指标建模 | 多数工作默认完整规则输入，输出侧重均值或类别 | 将观测过程、不确定性和风险纳入同一任务链 | 明确研究对象和应用价值 |
| 异步与缺失建模 | 插值、填充、缺失衰减、连续时间和事件模型 | 插值可能制造伪观测，不同方法难在统一协议下比较 | 研究保留时间、mask、通道和工况的规整表示 | 提出研究问题一 |
| 概率预测 | 独立高斯、分位数、生成式模型和条件流 | 单变量区间难表达协同变化，高维联合建模又不稳定 | 构建面向未来查询的概率状态预测 | 提出研究问题二 |
| 风险评估 | 独立分类、点预测阈值和后处理报警 | 预测与风险脱节，阈值可能依赖测试集 | 建立预测分布到校准风险的转换链 | 提出研究问题三 |

1.1 从设备连续运行、维护成本和多传感器监测需求切入。1.2 按上述四类方法范式综述，不把文献写成按年份排列的摘要集合。1.3 将文献边界压缩为三个可研究问题。1.4 给出三项研究内容和创新，并明确各自的实验判据。1.5 说明六章如何依次回答三个问题。

### 11.4 第二章的论证结构：从理论工具到方法选择

第二章不能只是概念词典。每一组理论都要说明它支持后文哪一个决策：

| 理论内容 | 已有方法关注点 | 本文需要它解决什么 | 后续落点 |
|---|---|---|---|
| 多元时间序列预测 | 均值预测、序列依赖、跨变量关系 | 定义历史窗口、预测窗口和多传感器目标 | 第三、四章任务形式化 |
| 异步与缺失建模 | 插值、mask、time gap、连续时间 | 区分观测值与观测过程 | 第三章规整表示 |
| 多尺度表示 | 局部模式、长期趋势和变量交互 | 解释为何同时保留局部与全局信息 | 第三章表示机制 |
| 条件概率预测 | 参数分布、分位数、生成模型和条件流 | 定义边际不确定性与相关结构 | 第四章概率方法 |
| 概率评分与区间 | NLL、CRPS、Energy Score、PICP、MPIW | 区分点精度、分布质量和联合质量 | 第四章实验判据 |
| 风险与校准 | 阈值、Platt、ECE、报警预算 | 保证风险分数可解释且不使用 test 调参 | 第五章风险机制 |

第二章每节采用“基本定义—代表性路线—适用假设—本文采用的概念—与后文接口”的结构。理论介绍到能够支撑后续公式和实验即可，不复述第一章研究现状，也不提前描述实验结果。

### 11.5 第三章的论证结构：别人如何处理异步观测，为什么需要规整表示

第三章围绕研究问题一形成独立闭环。

**别人怎么做。** 现有路线可分为规则化预处理、缺失感知递归模型、连续时间或事件模型、面向不规则序列的注意力与图模型。规则化方法实现简单且能复用成熟预测器；缺失感知方法显式利用 mask 和 time gap；连续时间方法能够处理任意时间间隔；事件模型避免构造完整规则网格。

**还缺什么。** 本文关注的不是证明上述方法普遍无效，而是它们在工业多通道、长历史、不同采样密度和连续离线并存时面临的共同权衡：规则化处理可能丢失观测语义，连续时间模型计算代价较高，单尺度表示可能遗漏长趋势或局部异常，不同数据集又缺少统一输入协议。

**我们为什么这样做。** 本文先统一事件和张量语义，再将时间、mask、通道身份与工况输入表示过程，通过全局与局部多尺度聚合得到变量级状态。这个选择把“数据如何被观测”与“设备处于什么状态”同时编码，又为后续概率模型提供固定接口。

**为什么可能更好。** mask 参与聚合可减少伪观测影响；多尺度路径分别覆盖长期退化和短时变化；通道身份与变量交互保留传感器差异和联动；工况条件减少相同观测值在不同运行状态下的语义混淆。这些是待验证的作用路径，而不是预设结论。

**怎么证明。** 表示质量由统一轻量头进行比较，时间、mask、通道、工况、多尺度和变量交互的贡献由受控消融识别，跨缺失率和缺失机制的实验用于检验稳定性。第三章的结果只支持表示层结论，不支持联合概率和风险结论。

第三章建议按“问题定义与符号—统一协议—数据适配—缺失机制—表示方法—独立实验—本章小结”展开。方法介绍后立即给出对应假设和消融关系，避免到实验部分才解释模块用途。

### 11.6 第四章的论证结构：别人如何表达不确定性，为什么需要查询条件概率预测

第四章围绕研究问题二展开，并以前一章的规整表示为固定输入基础。

**别人怎么做。** 点预测模型优化均值误差；对角高斯和分位数模型能够表达单变量尺度或区间；自回归、条件流、copula 和其他生成方法尝试建模复杂分布及变量依赖。这些路线分别在训练稳定性、计算效率、边际灵活性或联合表达方面具有优势。

**还缺什么。** 工业预测窗口同时包含未来时间和目标通道，同一历史状态需要回答多个不同查询。独立输出忽略跨变量协同，高维联合模型又容易出现计算量增长、数值不稳定和条件表示错位。仅报告边际 NLL 或 CRPS，也不足以证明变量依赖被正确建模。

**我们为什么这样做。** 本文把变量级历史状态转换为包含未来时间、目标通道和工况的查询项级条件表示，再分别处理边际分布、区间和相关结构。该设计将“预测哪一个时间点的哪一个变量”显式写入条件，而不是让一个共享输出头隐式猜测查询语义。

**为什么可能更好。** 查询映射能够减少历史变量与未来目标之间的语义错配；稳定的边际模型负责每个目标的不确定性；受控相关结构负责传感器和时间之间的共同变化；独立的区间目标可补充似然训练对覆盖率关注不足的问题。结构拆分也允许逐项消融和复杂度控制。

**怎么证明。** 比较点预测、独立高斯、边际概率和相关性感知完整模型；保持编码器与训练预算一致，只改变查询和概率结构；同时报告 MAE、RMSE、NLL、CRPS、PICP、MPIW 与 Energy Score，并检查采样稳定性、预测长度和计算开销。只有多变量评分和受控消融同时支持，才使用联合建模的强结论。

第四章建议按“概率预测动机—总体框架—查询条件—边际与相关结构—训练与推理—主实验—消融与敏感性—可视化—本章小结”展开。风险阈值和报警效果不在本章作为主要证据。

### 11.7 第五章的论证结构：别人如何做风险预警，为什么需要分布到风险的校准链

第五章围绕研究问题三展开，并固定使用第四章生成的预测输出。

**别人怎么做。** 常见路线包括独立故障分类、对点预测设置阈值、根据预测样本计算越界概率，以及对风险分数进行后处理校准。独立分类直接但与状态预测割裂；点阈值易解释但忽略不确定性；样本风险能够使用分布信息，但仍需要校准和报警规则。

**还缺什么。** 同一模型的预测误差、概率质量和风险识别能力可能并不一致。若风险分数来源不明确、阈值在测试集上搜索或不同数据集共用同一风险定义，较高 F1 也不能说明风险机制可靠。

**我们为什么这样做。** 本文区分分布派生风险和辅助监督风险，将未来越界概率、预测区间及窗口级不确定性转换为连续风险分数，再只使用验证集拟合校准器和确定报警预算。各数据集保留自己的风险语义，但共享同一防泄露评估流程。

**为什么可能更好。** 分布派生风险能够解释报警来自哪些未来变量和时间范围；概率校准改善分数刻度的可解释性；验证集阈值使测试结果保持独立；风险时间线和事件级评价比单一窗口分类指标更接近维护决策过程。

**怎么证明。** 对比原始分数、未校准 q95 和 Platt 校准 q95；固定阈值后报告 AUROC、AUPRC、F1、Precision、Recall、ECE、误报与漏报；在有明确故障时间时分析 Lead Time；通过缺失鲁棒性和典型案例解释风险结果何时可靠、何时失效。

第五章建议按“风险问题定义—风险分数来源—验证集校准与阈值—实验协议—风险识别—时间线案例—缺失鲁棒性—阈值敏感性—综合讨论—本章小结”展开。

### 11.8 第六章的论证结构：从三项证据回到一个总命题

第六章不再引入新方法或新结果。全文总结按“观测表示—概率预测—风险校准”复述三项已经获得的证据，并回答总命题是否成立。每项总结包含研究问题、采用的机制、最直接的实验依据和适用范围，避免只罗列模块名称。

局限性应与前文证据边界对应，包括人工异步与真实异步之间的差距、少故障事件导致的统计不确定性、跨数据集风险语义不可直接比较、高维相关建模的代价，以及离线校准面对分布漂移的限制。研究展望从这些局限自然推出，不增加与正文无关的新方向。

### 11.9 文献综述和“别人怎么做”的组织规则

- 按解决思路组织文献：规则化预处理、缺失感知、连续时间、事件建模、概率预测、联合相关、风险校准，而不是按年份或作者顺序罗列。
- 每类方法都说明“解决了什么、依赖什么假设、在本文场景下还缺什么”，先承认其有效部分，再提出边界。
- “已有研究不足”必须限定在工业异步多传感器概率状态预测任务中，避免使用“无法处理”“完全忽略”等无证据的绝对表述。
- 每个事实性判断和研究现状判断均对应可核验文献；方法设计动机可以由多篇文献共同支持，但不能把本文推断伪装成原文结论。
- 第一章说明研究版图和缺口，第二章解释理论机制，第三至第五章只回顾与本章方法选择直接相关的代表路线，避免重复综述。

### 11.10 可检验假设与章节证据

### 11.11 段落级写作模板

核心方法章节的一个论证单元可按以下顺序写成连续段落，而不是机械列点：

1. 交代研究对象、输入条件和具体困难。
2. 归纳两到四类已有方法及其有效性。
3. 将不足限定在本文数据条件、预测目标或评价要求下。
4. 引出本文机制，并说明它具体改变了哪一段信息流。
5. 从信息保留、概率定义、风险决策或计算代价解释预期优势。
6. 给出对应假设、对照模型、消融项和指标。
7. 根据结果说明成立范围、权衡和失败案例。

写作时，“别人怎么做”依赖文献，“我们怎么做”依赖方法定义和公式，“为什么可能更好”依赖机制分析，“实际是否更好”只能依赖实验数据。这四类句子不能相互替代。

### 11.12 章节之间的承接关系

| 承接位置 | 上一章已经回答 | 下一章仍需回答 | 过渡逻辑 |
|---|---|---|---|
| 第二章到第三章 | 已有理论可描述异步、缺失和概率问题 | 如何形成适用于工业数据的表示 | 从理论假设进入数据协议和表示实现 |
| 第三章到第四章 | 已获得并独立验证变量级规整表示 | 如何表达未来多变量不确定性 | 从确定性表示进入条件概率输出 |
| 第四章到第五章 | 已获得未来预测分布、样本和区间 | 如何形成可校准的运维风险 | 从概率质量进入决策质量 |
| 第五章到第六章 | 已验证风险排序、阈值和鲁棒性 | 总命题在什么范围内成立 | 汇总三层证据并限定外推范围 |

上述承接保证第三、第四、第五章不是三篇并列小论文，而是同一研究问题从观测、预测到决策的连续展开。

## 13. 结果与证据治理

每个可写入论文的实验结果必须能够追溯到：

```text
run_id
dataset 与数据版本
model 与模型版本
seed
split 文件
missing mask 文件
完整配置
checkpoint 及其选择依据
预测文件
校准文件
指标文件
运行环境与代码提交版本
```

结果使用规则：

- `result/` 下原始 metrics JSON 只读，不手工修订。
- 表格和图从原始结果自动构建，禁止人工复制后失去来源。
- 正文中的每个指标数字标注其数据集、协议、seed 汇总方式和校准口径。
- 当前文档中已有的示例数值，在缺少完整 `run_id`、checkpoint 和统计复核前，只能作为阶段观察。
- 模型状态分为“接口存在、smoke 通过、完整训练完成、正式结果可用”四级，不能仅以代码文件存在宣称实验完成。
- 新增引用后同步维护文献总表、正文参考文献和引用编号；引用编号按首次出现顺序排列。

## 14. 完整论文范围与最低闭环

| 观测过程感知的规整表示 | 时间、mask、通道或工况确实进入表示 | 简单插值后的完整序列 |
| 概率状态预测 | 输出合法概率、样本或分位数并有概率指标 | 只有点预测加误差条 |
| 相关性感知概率预测 | 有跨变量相关机制和多变量评价 | 仅独立边际输出 |
| 联合概率分布建模 | 满足联合建模证据门槛 | 仅采样时叠加共享噪声 |
| validation-only 校准 | 校准拟合与阈值均不使用 test | test best F1 阈值 |
| 风险识别能力 | 数据协议和标签定义明确 | 直接等同真实维护收益 |
| 辅助 RUL 风险标签 | RUL 只用于构造风险 | 概率 RUL 预测模型 |

## 16. 最终验收边界

整篇论文可以被认为形成严谨闭环，必须同时满足以下条件：

1. 三个研究问题、三项创新、第三至第五章和三组主实验证据一一对应。
2. 统一任务始终是未来多传感器概率状态预测，风险任务保持辅助定位。
3. 人工异步构造、非官方数据划分和数据集特定风险定义均被明确披露。
4. 创新一由轻量头独立验证，创新二由概率及多变量指标验证，创新三由固定校准协议验证。
5. 所有正式对比满足相同 split、mask、归一化、seed、预算和 checkpoint 选择规则。
6. 风险阈值和校准器完全不接触 test label。
7. 所有论文数值均有 `run_id`、配置、checkpoint 和原始结果文件支撑。
8. 少正类、窗口相关性、数据集差异和计算代价在统计分析与局限性中得到处理。
9. 结论强度不超过实验覆盖范围，未完成工作不写入创新结论。
10. 原始文档、实验结果和引用关系在后续修改中保持可追溯。

## 17. 总体结论

本论文不应被组织成“KAFNet 与 ProFITi 的模块缝合”，也不应被组织成“一个大模型同时输出所有指标”。最稳健的总体结构是围绕三个逐层递进的科学问题形成完整证据链：

```text
观测过程如何被保真表示
  -> 未来状态不确定性如何被概率化表达
  -> 预测分布如何被校准为可解释风险
```

对应的三项核心创新是：

1. 观测过程感知的工业异步多传感器规整表示方法。
2. 查询条件驱动的多传感器概率状态预测方法。
3. 由预测分布到工业风险的验证集校准评估机制。

模型、数据集、基线、图表和代码均应围绕这三项创新提供证据。这样既能够容纳 KAFNet、ProFITi、KST ProbFlow 及后续改进，也能保证整篇毕业论文的研究问题、技术路线、实验设计和结论边界始终一致。
