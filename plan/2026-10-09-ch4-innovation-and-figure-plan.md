# 第四章创新点与实验图表重构方案

日期：2026-10-09。状态：研究方案，未实施、未形成性能结论。当前主基线为 Unified V3C；本文件不替代已冻结的数据协议。

## 1. 推荐主线与章节边界

建议标题：**基于多尺度状态表征的条件化不确定性预测与校准**。

核心研究问题：在保留第三章点预测能力的前提下，V3C 的多尺度状态信息能否帮助模型识别“何时、哪个传感器、哪个预测步更不确定”，并在相近覆盖水平下获得更窄、更可靠的预测区间？

这是一项待验证假设，不是已经成立的贡献。第三章研究表征与点预测；第四章研究预测不确定性的质量；第五章消费冻结概率产物研究风险决策。报警阈值、提前量、检测延迟和误报负担的应用比较主要放在第五章，避免章节重复。

不再把旧方案中的联合 flow、copula、顺序与秩敏感性作为必做实验。现有分位数头不构成联合概率密度，不能据此声称联合建模。

## 2. 当前实现的前置问题

- `code/kaf_profiti/models/unified/heads/state.py` 和 `rul.py` 的 loss 优先判断 point；forward 在分位数模式也返回 point，导致分位数 pinball 分支未按预期训练。必须先修复并测试所有分位数对应参数的梯度与训练行为。
- 默认分位数为 0.1/0.5/0.9，只对应中央 80% 区间。不能从它们直接报告 90% 或 95% 区间。
- FD004 的 cap 标签和 raw RUL 是不同预测对象；只用 capped 标签训练不能直接声称学习了 raw RUL 条件分布。
- TEP 检测 sigmoid 与诊断 softmax 独立输出，需检查检测概率与 1-P(normal) 的一致性；不能把两种损失的和当作单一分类 NLL。
- 当前交接文件尚未完整冻结三个数据集的基准 run 身份。先核验 checkpoint 配置、split、目标语义和 evaluator，再形成第四章对照。

上述属于正确性与协议修复，不计为算法创新。概率 evaluator 和产物能力需逐项核验，不能直接以历史进度记录判断当前是否完成。

## 3. 候选贡献：一个核心机制，两组验证

### 3.1 核心候选：多尺度条件化非对称分位数头

保留 V3C 编码器，用其实际输出的尺度级 token 与传感器表示构造不确定性分支。不得把尺度 token 描述为完整的逐 patch 时间序列。

第一步固定第三章编码器和点预测分支，单独学习中位数修正与左右尾宽；第二步才将联合微调作为独立对照。中位数不强制等于已有点预测，尤其不能将使用非对称 RUL 损失训练的点预测直接称为中位数。

建议机制：用传感器/任务状态和预测步 embedding 查询不同尺度表示，得到条件化特征；由该特征分别产生中位数修正、下尾增量和上尾增量。以 softplus 正增量从中位数向两侧累计，保证分位数有序。尺度加权只是候选机制，不预先解释为因果重要性。

建议预先固定分位数集合为 0.025/0.05/0.1/0.25/0.5/0.75/0.9/0.95/0.975，可计算 50%、80%、90%、95% 区间与 WIS。训练使用覆盖全部分位数的 pinball loss；各分位数权重和辅助点损失权重显式记录。

必要控制：普通拼接 MLP、参数量近似匹配的加宽 MLP、条件化尺度加权头。若加宽 MLP 已获得相同收益，则不能把收益归因于尺度路由。

### 3.2 可靠性验证：条件误差与验证集校准

先比较未校准、全局区间校准、预定义分组校准。分组来自历史输入可得条件，不使用真实未来 RUL 或测试误差选组。组数、边界、最小样本量和小组回退规则在测试前确定。

校准本身是成熟技术，不单列为原创算法。若要提出新校准机制，必须先与适用的标准方法做文献核验和严格对照。时间依赖和漂移下，不声称任意条件下的分布无关有限样本覆盖保证。

### 3.3 跨任务验证：统一表征，不强迫统一概率形式

| 数据集 | 概率对象 | 适配方式 | 必须说明的边界 |
|---|---|---|---|
| MetroPT-3 | 未来多传感器状态边际分位数 | 传感器、预测步条件化尾宽 | 边际覆盖不等于整段轨迹联合覆盖 |
| FD004 | 单发动机 raw RUL 分位数 | 退化状态条件化非对称尾宽 | 概率分支使用 raw 标签；原 cap150 点预测可作为保留支路 |
| TEP | 正常及各故障类别概率 | 类别概率头与 validation-only 温度校准 | 分类扩展验证，不声称使用了回归分位数机制 |

FD004 建议首先采用“冻结 cap150 点预测基线 + raw 标签概率分支”。所有概率对照均用相同 raw 标签，单独报告概率中位数和旧点分支的误差；如比较 capped 分布，应另表列出，不能混用指标。

TEP 优先评估从同一个诊断 softmax 推导 P(fault)=1-P(normal) 的一致性方案，并与原双头作对照。TEP 不自动执行实验，仅纳入后续扩展计划。

## 4. 实验矩阵与公平性

| 编号 | 要回答的问题 | 对照 | 主要证据 |
|---|---|---|---|
| E0 | 概率链路是否真正训练和正确反归一化 | 合成分布、分位数梯度、序列化回放测试 | 梯度、排序、单位、分数一致性 |
| E1 | 条件化机制是否有效 | 同一冻结 V3C：全局残差区间、普通分位数 MLP、加宽 MLP、候选头 | Pinball/WIS、覆盖误差与宽度、参数量 |
| E2 | 收益来自编码器还是概率头 | Unified、TCN、GRU、PatchTST、TimesNet、iTransformer 接相同普通分位数头 | 同协议概率主表 |
| E3 | 校准是否必要且足够 | 未校准、全局校准、分组校准 | 匹配覆盖下宽度、分组覆盖误差 |
| E4 | 哪个设计产生收益 | 去尺度条件、去预测步条件、对称尾宽、冻结与联合微调 | 同预算消融；FD004 不做无意义的预测步消融 |
| E5 | 可靠性在何处失效 | 按时间块、工况、预测步、退化阶段分层 | 子组覆盖、样本数、漂移局限 |

E2 先建立共同概率头的公平对照，不强求异构模型输出相同内部 token。TCN 必须先解决当前数值稳定性问题，不能把失败训练作为有效排名证据。旧点预测结果不能填入概率指标主表。

MetroPT 保持首月开发、其余测试；首月内部按时间隔离 train、validation-selection 和 calibration。FD004 按 engine 隔离，TEP 按 run 隔离。校准不得使用 test，也不重复使用参与训练的样本拟合。若细分导致样本不足，先制定交叉拟合方案，不默默混用 validation 选择与校准。

所有统计量仅由 train 拟合。重划 validation 后须更新可读 split identity，并对所有受影响模型一致处理，不与旧划分结果直接做排名。固定训练预算和调参预算；单 seed 先做可行性筛选，正式稳定性结论需要后续多 seed。已有测试集被反复用于开发，应如实报告这一局限；未来确认性评价需要未参与开发的保留数据或新数据。

## 5. 指标与统计单位

- MetroPT/FD004：Pinball、WIS、各名义水平 PICP、MPIW、覆盖绝对误差，同时报告中位数 MAE/RMSE。FD004 保留 raw NASA score 作为点预测补充。
- MetroPT 逐传感器保留原始单位；跨传感器汇总概率分数应使用明确的 train-derived 标准化尺度，不能将不同单位的区间宽度直接平均解释。
- TEP：诊断 multiclass NLL、明确求和约定的 Brier score、ECE 与可靠性图；检测单独报告 binary NLL/Brier。Macro-F1 和 Balanced Accuracy 是辅助辨别能力指标。
- 仅有离散分位数时不报告精确 CRPS 或密度 NLL；若数值积分近似 CRPS，应明确分位数网格、尾部处理与近似性质。没有联合样本则不报告 Energy Score 或联合覆盖结论。
- MetroPT 使用预定义时间块、FD004 使用 engine、TEP 使用 run 做成组或配对 bootstrap；不能把重叠窗口视为独立样本。单 seed 的 bootstrap 不代表训练随机性。
- 分组结果同时列样本数及独立单位数；真实 RUL 分层可用于事后诊断，但不能输入推理或在线校准分组。

## 7. 推荐章节结构

4.1 问题定义与不确定性来源；4.2 V3C 条件化非对称分位数建模；4.3 校准与跨任务概率接口；4.4 概率质量比较及模块消融；4.5 条件可靠性、局限与第五章输出契约；4.6 小结。

不强凑三个独立算法创新。可成立的叙事是“一项条件化建模机制 + 严格可靠性评价 + 跨任务接口验证”。分位数回归、正增量防交叉、温度缩放、共形校准均非本项目原创。机制是否区别于已有条件分位数/多尺度不确定性方法，需后续检索原文核验；本次未完成该项查新。
